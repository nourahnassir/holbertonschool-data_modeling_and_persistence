# SQL - Joins & Relationships

This project is part of the Holberton School curriculum, focusing on advanced SQL queries, multi-table relationships, and data persistence.

## Learning Objectives
- Understanding table relationships (1-1, 1-N, N-N).
- Utilizing primary and foreign keys to connect data.
- Writing complex SQL queries using `INNER JOIN`, `LEFT JOIN`, and subqueries.
- Managing relational databases using SQLite.

## Directory Structure
- `sql_crud/`: Contains previous queries and tasks related to single-table CRUD operations.
- `sql_join/`: Contains SQL scripts utilizing joins and multi-table relationships (e.g., `1-books-with-authors.sql`).

## Requirements
- Ubuntu 20.04
- SQLite 3.x
