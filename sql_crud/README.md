# SQL - CRUD Operations

This project is part of the Holberton School curriculum, focusing on learning **Structured Query Language (SQL)** and the core **CRUD** (Create, Read, Update, Delete) operations using SQLite.

## Learning Objectives
- Understand the relational model (tables, rows, and columns).
- Write standard SQL queries to define and manipulate data.
- Perform `INSERT`, `SELECT`, `UPDATE`, and `DELETE` operations.
- Filter, sort, and aggregate data using SQL clauses and functions.

## Requirements
- Operating System: Ubuntu 20.04 (for grading)
- Database System: SQLite 3.x
- Each task is implemented in a separate `.sql` file.
